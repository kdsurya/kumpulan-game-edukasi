# Prompt satu tim lawan komputer
buatkan web game tarik tambang untuk pengenalan jaringan untuk smk kelas 10, yang berisi 5 pertanyaan seputar jaringan, tim kiri yang menjawab benar tali akan mengarah ke kiri demikian juga sebaliknya kalo menjawab salah akan bergerak ke kanan. jika semua pertanyaan dijawab benar maka tim kiri atau siswa itu menang. tim kiri adalah siswa, tim kanan adalah komputer.

# Prompt dua tim
buatkan game web tarik tambang dengan ketentuan berikut:
- ada 2 tim yang bermain, tim kiri dan kanan
- setiap soal muncul bergantian untuk tim kiri dan kanan
- tiap kali soal untuk tim kiri muncul dan dijawab benar maka tali nya akan ke kiri. kalo tidak benar talinya ke kanan. demikian juga untuk tiap soal tim kanan.
- buat soalnya 5 soal untuk masing-masing tim dengan topik yang sama untuk masing-masing soal untuk tiap tim.
- materinya tentang pengenalan jaringan.
